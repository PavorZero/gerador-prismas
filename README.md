# Gerador de Prismas

Web app para gerar apresentações personalizadas a partir de uma planilha Excel
e um template PowerPoint.

## Como usar

1. Envie o arquivo Excel com os dados
2. Escolha a aba e mapeie as colunas (Nome, Cargo, Empresa)
3. Envie o template `.pptx` com os textos NOME, CARGO, EMPRESA
4. Clique em Gerar Prismas
5. Baixe o arquivo gerado

## Tecnologias

- Streamlit
- pandas
- python-pptx
